# 聚会游戏列表说明文档 (Party Games Index)

本目录 (`party-games/games/`) 包含 **15 款独立运行的 HTML5 游戏**。每个 `.html` 文件均为完全独立的单文件应用，可在浏览器中双击直接运行，亦可通过主大厅 (`party-games/index.html`) 进行无缝跳转体验。

## 页面公共架构 (Architecture & Common Elements)

每个 standalone HTML 页面均集成了以下公共能力：
- **引入库依赖**：`../three.min.js`, `../OrbitControls.js`, `../mqtt.min.js`
- **导航控制**：顶部带有 `🏠 返回大厅` 和 `← 返回大厅` 按钮，直接返回 `../index.html`
- **模式切换**：支持 🤖 AI 对战、👥 同屏双人、🌐 在线联机 (视游戏类型)
- **音效引擎**：内置 Web Audio API 纯合成音效系统（免除外部音频资源依赖）
- **通用组件**：包含得分记分板、实时房间 ID 状态、Toast 浮窗提示与模态弹窗
