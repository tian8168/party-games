# 🎮 聚会游戏大厅 (Arcade Party Hub)

> 纯原生 Web 技术栈驱动的轻量级双人/多人经典对抗与博弈游戏聚合平台。零大型框架开销，极速秒开，支持人机对战、本地同屏与 MQTT 实时联机。

---

## 🌟 平台特性 (Features)

* **14 款完整游戏矩阵**：涵盖经典策略博弈、物理碰撞对抗、心理博弈与手速反应。
* **多维度对战架构**：
  * **人机对弈 (AI Engine)**：内建 BFS 寻路评估、贪心剪枝与几何射线检测等独立 AI 决策模型。
  * **本地同屏 (Local Multiplayer)**：支持单键盘分区分键位（WASD / 方向键 / ESDF / 鼠标）及触控设备同屏对抗。
  * **好友联机 (Online Network)**：基于 MQTT 异步发布订阅（Pub/Sub）协议实现轻量级去中心化房间协同。
* **高性能图形与音频管线**：
  * **2D Canvas 精准栅格**：自适应设备像素比（DPR）动态高分屏渲染。
  * **3D WebGL 立体渲染**：基于 Three.js 构筑空间几何体、360° 轨道控制器与空间射线拾取（Raycaster）。
  * **Web Audio 纯合成音效**：通过正弦波、方波振荡器与动态增益节点实时合成击发、落子与终局音效，无外部音频文件网络等待。
* **全平台多端适配**：响应式视口布局，桌面端键鼠与移动端虚拟十字摇杆/按键无缝自适应。

## 🚀 运行与部署 (Getting Started)

### 本地直接运行
本项目为纯前端轻量化工程，无需强制构建流程：
```bash
# 方式 1: 直接使用浏览器打开
双击 index.html 即可在本地浏览器完整运行所有游戏

# 方式 2: 使用静态服务器运行 (推荐)
npx serve .
# 或
python -m http.server 8080
```

### 部署至 Cloudflare Workers / Pages
项目原生包含 `wrangler.json` 静态资产托管配置：
```bash
# 登录 Cloudflare
npx wrangler login

# 部署上线
npx wrangler deploy
```
